# SHACK66 Restaurant Website

A responsive restaurant website built with React 18 and Vite. The design uses a dark background with gold accents and includes the restaurant's supplied food photography.

## Run locally
Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Included updates
- Local SHACK66 food photos in `public/images/` (no Unsplash placeholder images).
- Restaurant phone, email, address, opening hours (3:00 PM–6:00 AM), Google Maps directions, and Instagram link.
- Responsive navigation, menu category filters, gallery, and direct contact links.

## Important before publishing
Menu item labels are descriptive labels based on the supplied photos, not a verified official menu. No prices are shown because confirmed prices were not provided. Confirm the official menu and business hours before launch. The site provides direct call/email/map links; it does not process online orders or reservations.
